PROJECT 02 / AGENTIC AI

Financial Multi-Agent Chatbot

A financial multi-agent harness that coordinates specialist ReAct loops, tool execution, and financial data access.

Organization
Techcombank Securities

During Jun 2023 – Jan 2025 role
Core tools
LangGraph · ReAct loops · Python · pandas
INSIDE THE PROJECT
The challengeThe approachMy contributionOutcome & perspective

The challenge

Financial analysis brings together several kinds of reasoning: market signals, company fundamentals, strategy, and portfolio considerations. A conversational workflow needs a way to coordinate these perspectives while working with quantitative data.

The approach

I developed a LangGraph harness with four ReAct-style agents: technical, fundamental, strategy, and manager. The harness connects agent reasoning with tool execution, observations, coordination, and controls for running the workflow.

01. Coordinate through the manager

The manager plans and delegates analytical tasks to the specialists, collects their findings, and synthesizes the financial analysis. LangGraph orchestrates the workflow and carries context between its steps.

02. Run specialist agent loops

Each specialist follows a ReAct-style loop: reason about the task, choose a tool, execute it, inspect the observation, and decide whether to continue or return findings. Technical, fundamental, and strategy agents contribute their respective perspectives.

03. Connect computation and evidence

Python execution and pandas support calculations and DataFrame operations. Market-data tools, SQL queries, and document retrieval provide financial data and supporting information for the analysis. Tool results return to the agent loop as observations.

04. Control and inspect execution

Execution limits bound the agent runs, retries support recovery from failures, and tracing makes the sequence of agent steps and tool calls inspectable. These controls surround the tool-use loop as part of the harness.

My contribution

Developed the four-agent chatbot and LangGraph orchestration, connected Python and pandas with financial data and retrieval tools, and incorporated execution limits, retries, and tracing around the agent loops.

Outcome & perspective

A multi-agent financial chatbot supporting coordinated analysis and portfolio reasoning through LLM-driven workflows.

The harness combines specialist reasoning with tool access, feedback from execution, and operational controls. This lets the agents work through quantitative tasks iteratively and bring their findings together within one workflow.
