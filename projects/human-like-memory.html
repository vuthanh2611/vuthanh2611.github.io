PROJECT 01 / CONVERSATIONAL AI

Human-Like Memory for an HR Chatbot

A layered memory system that helps an HR chatbot retain context, retrieve relevant knowledge, and update what it remembers over time.

Organization
Minglo–Atrae
Context
Feb 2025 – Mar 2026
Core tools
Neo4j · FastAPI · Redis · RabbitMQ
INSIDE THE PROJECT
The challengeThe approachMy contributionOutcome & perspective

The challenge

A useful HR conversation often depends on context shared earlier. Keeping only the latest messages limits continuity; bringing every past exchange into each response creates a different set of retrieval and latency challenges.

The approach

I designed and deployed a memory module that combines recent conversational context, summaries of earlier turns, and long-term memories retrieved from a knowledge graph. Memory updates run asynchronously, while periodic reflection maintains and enriches long-term memory.

01. Assemble conversation context

The memory module assembles conversation context from sensory memory containing the most recent 5–10 turns, summaries of earlier conversation turns, and relevant long-term memories. This context is supplied to the chatbot to support continuity across conversations.

02. Retrieve relevant long-term memories

Hybrid keyword and vector retrieval is called to fetch relevant memories from the Neo4j knowledge graph. The retrieved information becomes part of the conversation context alongside recent turns and conversation summaries.

03. Update memory asynchronously

RabbitMQ queues background work for conversation summarization and memory ingestion. FastAPI exposes the service and Redis supports caching, keeping these updates off the response path.

04. Reflect within long-term memory

Reflection is triggered periodically, every few hours or days, rather than on every response. It operates within long-term memory to enrich stored knowledge, merge related memories, and remove conflicting entries.

My contribution

Designed and deployed the cognitive memory system, integrated graph representation and hybrid retrieval, implemented periodic reflection to enrich, merge, and resolve conflicts in long-term memory, and connected asynchronous memory processing to the serving APIs.

Outcome & perspective

A deployed memory module for production chatbot integration, with background summarization and ingestion designed to preserve responsiveness.

The memory module supplies conversation context by combining recent turns, earlier summaries, and retrieved long-term memories. RabbitMQ handles background updates, while reflection runs periodically within long-term memory to maintain and enrich the stored knowledge.
