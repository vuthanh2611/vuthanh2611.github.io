PROJECT 03 / DOCUMENT AI

Bond Document Chatbot for Relationship Managers

A conversational document assistant combining contextual retrieval, reranking, and source-linked answers for relationship managers.

Organization
Techcombank Securities
Context
During Jun 2023 – Jan 2025 role
Core tools
LangChain · Qdrant · Titan · AWS Bedrock
INSIDE THE PROJECT
The challengeThe approachMy contributionOutcome & perspective

The challenge

Bond documents contain detailed information that internal teams need to locate and interpret. The goal was to make those materials easier to query through a conversational interface.

The approach

I built a LangChain RAG workflow with two stages: preparing financial documents for retrieval, then answering questions using selected source passages. The system combines Qdrant, Titan embeddings, and Claude through AWS Bedrock, with conversation-aware retrieval and reranking.

01. Prepare and index the documents

Document text is extracted and cleaned, then divided into retrievable passages with source metadata. Titan embeddings represent those passages as vectors, which are stored in Qdrant alongside their metadata.

02. Build a contextual retrieval query

The relationship manager’s question is combined with relevant conversation history to rewrite follow-up questions into a contextualized retrieval query. Titan embeds the query for vector search in Qdrant, with metadata filters narrowing the search.

03. Rerank and assemble the evidence

A reranking step reorders the retrieved candidate passages for relevance to the question. Selected passages are assembled with the question into the context supplied to Claude on AWS Bedrock.

04. Check answers and preserve source references

The workflow checks the generated answer against the retrieved context and includes source citations so relationship managers can inspect the supporting material.

05. Connect the prototype to production

LangChain orchestrates the retrieval and answering workflow. I used Streamlit for rapid prototyping and collaborated with developers on the production version for internal teams.

My contribution

Built the document RAG workflow, connecting ingestion, conversation-aware query rewriting, filtered retrieval, reranking, answer checks, and source citations. Prototyped the interface in Streamlit and collaborated with developers on production delivery.

Outcome & perspective

A production-ready document chatbot enabling internal teams to query financial materials and extract structured insights.

The workflow separates document preparation from interactive Q&A. Contextual queries, metadata filters, and reranking shape the evidence supplied to the model, while answer checks and citations help users assess the response against the source materials.
